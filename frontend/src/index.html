Pegasus

Running on port 8080

Fitur Pegasus

  • Panel desktop native untuk macOS, Windows, dan Linux.
  • API perangkat berjalan lokal pada port yang dapat diatur.
  • Pilih field yang disertakan dalam respons API.
  • Aplikasi dilindungi kata sandi; default: 12345678.
  • Server dapat dijalankan atau dihentikan tanpa menutup aplikasi.
  • ID perangkat dan client key tersimpan untuk penggunaan berikutnya.
  • Frontend dan backend dikemas dalam satu aplikasi.

Buka endpoint API

Data perangkat — http://localhost:8080/getdevice Status API — http://localhost:8080/health
Kata Sandi Aplikasi

Atur kata sandi untuk membuka Pegasus.

Field yang Ditampilkan

Pilih informasi perangkat yang disertakan dalam respons API.

Latar Belakang

Atur perilaku Pegasus di system tray dan saat Anda masuk ke komputer.
